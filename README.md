# Student Result Management System

A menu-driven Python program that manages student records and results
for a school.

## Features
- Add, view, search, update and delete students
- Record at least five subject scores per student and update scores
- Calculates total, average and grade (A to F)
- Report cards, results sorted by average or name, class statistics
- Saves a text report to the `reports/` folder
- Data is saved automatically in `data/students.json`

## How to run
1. Install Python 3.8 or newer.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run: `python main.py`

## Project files
| File | Purpose |
|---|---|
| main.py | Menu and user input |
| student.py | Student class and validation |
| results.py | Scores, grading and statistics |
| storage.py | Loading and saving JSON data |
| reports.py | Sorting and report generation |

## Grading scale
A: 70-100 | B: 60-69 | C: 50-59 | D: 40-49 | F: below 40
